## Importante

- A identidade visual aprovada é preservada, sem alterações.
- Os componentes e a home são protótipos em revisão, não uma loja em operação.
- As opções de slogan, manifesto e personalidade são propostas, não aprovações finais.
- A etiqueta “Orgânico” é informativa e somente pode ser aplicada a produtos com condição orgânica comprovada.

**Origem privada:** este repositório recebe apenas os arquivos públicos de visualização. As futuras atualizações serão sincronizadas pela automação da branch de desenvolvimento após a configuração da credencial restrita.
